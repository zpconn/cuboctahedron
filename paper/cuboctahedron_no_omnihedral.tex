Exact Reductions and Lean-Checked Certificates}
\author{Zach Conn}

\begin{abstract}
A periodic billiard trajectory in a polyhedron is \emph{omnihedral} if, during
one period, it reflects exactly once from every face, and \emph{nonsingular}
if every reflection point lies in the relative interior of a face.  We
describe a formalization in the Lean~4 proof assistant, using the mathlib
library, aimed at proving that the cuboctahedron has no nonsingular
omnihedral periodic billiard trajectory.  Every step uses exact rational and
integer arithmetic and is checked by the Lean kernel.  External programs may
propose certificates, but none of them is trusted.

The formalization reduces the problem, in checked steps, to a finite case
analysis over $97{,}297{,}200$ words in the seven pairs of parallel faces.
Its main structural ingredient is a \emph{holonomy normal form}: a scan of
the word that tracks square-face parity and a reduced stack of triangular
reflections, and that decides exactly when the linear part of the unfolded
return map is the identity, by a short argument modulo~$3$.  This splits the
problem into two branches.  In the identity branch the return map is a
translation, and each case reduces to the infeasibility of a strict
two-variable rational linear system, certified by Farkas multipliers.  In the
nonidentity branch the return map forces an invariant axis.  The hardest
nonidentity cases are handled by finite-state potential certificates, which
we call Bellman certificates.  They bound an exact geometric margin for whole
families of words at once.

At the time of writing, the main theorem is proved conditionally.  Lean
checks that a complete finite coverage object implies the billiard theorem,
and the construction of that object is ongoing.  We state precisely what is
checked, what is assumed, and what remains.
\end{abstract}

\section{Introduction}

A billiard trajectory in a polyhedron is a broken line that travels at
constant speed inside the polyhedron and reflects specularly from its faces.
At each reflection the tangential component of the velocity is preserved and
the normal component is reversed.  The trajectory is \emph{periodic} if, after
finitely many reflections, it returns to the same position with the same
velocity.  It is \emph{nonsingular} if no reflection point lies on an edge or
at a vertex, so that the reflecting face is always uniquely determined.  The
cuboctahedron has fourteen faces.  We call a period \emph{omnihedral} if its
fourteen reflections meet all fourteen faces, each exactly once.

\begin{theorem}[Target theorem]\label{thm:target}
The cuboctahedron has no nonsingular omnihedral periodic billiard
trajectory.
\end{theorem}

\paragraph{Background.}
Periodic billiard trajectories in polygons are classical;
Tabachnikov~\cite{tabachnikov} gives an introduction.  In an acute triangle,
Fagnano's orbit reflects exactly once from each side.  For rational polygons,
Masur proved that periodic directions are dense~\cite{masur}.  Boshernitzan,
Galperin, Kr\"uger, and Troubetzkoy proved that periodic orbits are dense in
the phase space~\cite{bgkt}.  Far less is known for polyhedra.  Stenman
exhibited a periodic orbit of length four in the regular
tetrahedron~\cite{stenman}.  B\'edaride and Rao proved that every regular
simplex carries periodic billiard orbits~\cite{bedaride-rao}.  Ceki\'c,
Georgiev, and Mukherjee studied periodic tubes in convex polyhedral billiards
in connection with eigenfunction concentration~\cite{cekic-georgiev-mukherjee}.
Theorem~\ref{thm:target} is a nonexistence statement of a different kind.  It
concerns one specific polyhedron and one combinatorial type of period, and its
proof is a large but finite exact case analysis.

\paragraph{Formalization.}
Theorem~\ref{thm:target} was first suggested by an exhaustive computer search
in floating-point arithmetic.  Such a search is not a proof.  The purpose of
the present work is to replace it with a proof checked in
Lean~4~\cite{lean} using the mathlib library~\cite{mathlib}.  A Lean theorem
is checked by a small logical kernel, while a Lean definition can also be
executed or simplified during checking.  This distinction matters here
because the finite search space is large.  All arithmetic in the proof is
exact rational or integer arithmetic.  The development uses no floating-point
numbers, numerical tolerances, \texttt{native\_decide}, or project-specific
axioms.  External programs are used to find certificates, but they are not
trusted.  A generated file contributes to the proof only when Lean checks a
theorem strong enough to rule out the corresponding geometric cases.  The
development is available at
\url{https://github.com/zpconn/cuboctahedron}.

\paragraph{What is proved.}
Call a finite case split \emph{covered} when Lean has proved, for every case
in the split, that the case satisfies one of the checked obstruction
predicates.  The current main theorem packages complete coverage in a Lean
structure named \texttt{ExhaustiveGeneratedCoverage} and proves:
\begin{verbatim}
theorem Cuboctahedron.conditional_cuboctahedron_no_omnihedral
    (coverage : ExhaustiveGeneratedCoverage) :
    Not (exists o : BilliardOrbit14,
      o.Nonsingular /\ o.Periodic /\ o.TouchesEachFaceExactlyOnce)
\end{verbatim}
The entire bridge from complete finite coverage to the billiard theorem is
therefore checked.  Along the way, Lean proves the following unconditionally:
\begin{enumerate}[leftmargin=2em]
\item every started omnihedral billiard orbit yields an unfolded
  straight-line witness (Section~\ref{sec:words});
\item there are exactly $97{,}297{,}200$ valid started pair words, and a
  verified ranking bijection enumerates them (Section~\ref{sec:words});
\item the holonomy classifier: the linear return map is the identity if and
  only if a reduced triangular shadow is empty (Section~\ref{sec:holonomy});
\item every obstruction certificate format used in the two branches of the
  case split is sound
  (Sections~\ref{sec:nonidentity}--\ref{sec:translation}).
\end{enumerate}
Each of these theorems, like the conditional main theorem, depends only on
the standard axioms \texttt{propext}, \texttt{Classical.choice}, and
\texttt{Quot.sound}.  What remains is to construct the coverage object from
generated Lean modules.  At the time of writing, coverage has been checked
end to end only on a pilot window of the case space
(Section~\ref{sec:coverage}).

\paragraph{Organization.}
Every project-specific term is introduced before it is used.
Section~\ref{sec:model} gives the exact cuboctahedron and reflection model.
Section~\ref{sec:words} explains the unfolding reduction and the finite word
space.  Section~\ref{sec:holonomy} proves the checked normal form for the

Finally, Sections~\ref{sec:coverage} and~\ref{sec:validation} state precisely
what is trusted, what is generated, and what remains conditional.

\section{The Exact Cuboctahedron Model}
\label{sec:model}

We use coordinates in \(\R^3\).  The cuboctahedron is the polyhedron
\[
P=\{(x,y,z)\in\R^3:
 |x|\le 1,\ |y|\le 1,\ |z|\le 1,\
 \epsilon_1x+\epsilon_2y+\epsilon_3z\le 2
 \text{ for all }\epsilon_i\in\{\pm1\}\}.
\]
It has six square faces,
\[
X_\pm:\ \pm x=1,\qquad
Y_\pm:\ \pm y=1,\qquad
Z_\pm:\ \pm z=1,
\]
and eight triangular faces,
\[
T_{\epsilon_1\epsilon_2\epsilon_3}:
\epsilon_1x+\epsilon_2y+\epsilon_3z=2,
\qquad \epsilon_i\in\{\pm1\}.
\]

Every face \(F\) is stored by a rational normal vector \(n_F\in\Q^3\) and a
rational offset \(c_F\in\Q\), so the supporting plane is
\[
  n_F\dotp p=c_F.
\]
Reflection in this plane is the affine map
\[
  r_F(p)=p-2\,\frac{n_F\dotp p-c_F}{n_F\dotp n_F}\,n_F.
\]
It has the form
\[
  r_F(p)=L_Fp+d_F,
\]
where \(L_F\) is a linear map and \(d_F\) is a translation vector.  Since all
normals and offsets are rational, every entry of \(L_F\) and \(d_F\) is
rational.

\paragraph{The formal model.}
In Lean, a candidate period is a structure \texttt{BilliardOrbit14}.  It
records impact points \(p_0,\ldots,p_{14}\), velocities, the face struck at
each of the fourteen impacts, and positive flight times.  Its fields assert
four things: each impact lies in the relative interior of its face, each
segment stays in \(P\) and lies in its interior away from the endpoints,
consecutive velocities obey the reflection law, and the trajectory closes up
with \(p_{14}=p_0\) and final velocity equal to initial velocity.  The
predicate \texttt{TouchesEachFaceExactlyOnce} says that the map from impact
indices to faces is a bijection.  To trust the statement of the main theorem,
a reader needs to audit only these definitions, together with the face data
and the reflection formula above.

\section{From Billiards to Finite Words}
\label{sec:words}

The standard way to study a billiard trajectory is to \emph{unfold} it.
Instead of reflecting the velocity vector when the trajectory hits a face,
reflect the next copy of the polyhedron across that face.  In the reflected
copies the trajectory becomes a straight line.  Conversely, a straight line
through reflected copies folds back to a billiard trajectory when each
crossing lies in the relative interior of the prescribed face.

\begin{definition}[Face itinerary]
A \emph{face itinerary} of length \(14\) is a function
\[
  s:\{0,\ldots,13\}\to\F,
\]
where \(\F\) is the set of the fourteen faces.  The itinerary is
\emph{omnihedral} if it is a bijection.  It is \emph{started} if
\[
  s(0)=X_+.
\]
\end{definition}

For a face itinerary \(s\), define its unfolded return map by composing the
fourteen face reflections:
\[
  A_s=r_{s(13)}\circ\cdots\circ r_{s(0)}.
\]
Write
\[
  A_s(p)=M_sp+b_s
\]
for its linear part \(M_s\) and translation part \(b_s\).

\begin{definition}[Unfolded witness]
An \emph{unfolded witness} for \(s\) is a line
\[
  \ell(t)=p+tv,\qquad v\ne0,
\]
such that the developed line crosses the reflected faces in the order
prescribed by \(s\), every crossing lies in the relative interior of that
developed face, and the affine return map \(A_s\) carries the line to itself.
In particular, the direction satisfies
\[
  M_sv=v.
\]
\end{definition}

\begin{lemma}[Unfolding criterion]
A nonsingular billiard orbit with face itinerary \(s\) exists if and only if
there is an unfolded witness for \(s\).
\end{lemma}

\begin{proof}
Reflect the next copy of the cuboctahedron instead of reflecting the velocity
vector.  This makes the billiard segments collinear.  Reflection preserves
relative interiors of faces, so the nonsingularity condition is unchanged.
Periodicity is exactly the statement that the affine return map identifies
the final developed line with the initial one.  Folding the reflected copies
back reverses the construction.
\end{proof}

\begin{lemma}[Starting-face reduction]
If a nonsingular omnihedral period exists, then one exists whose itinerary is
started.
\end{lemma}

\begin{proof}
An omnihedral period meets \(X_+\) exactly once.  Cyclically reindex the
period so that this reflection is first.
\end{proof}

\begin{remark}
Nonexistence needs only the forward implication of the unfolding criterion,
and only that implication is formalized.  The Lean theorem
\leanref{billiard\_implies\_unfolded} constructs an unfolded witness for the
itinerary of any omnihedral billiard orbit whose first face is \(X_+\).  The
theorem \leanref{can\_start\_at\_xp} performs the cyclic reindexing.
\end{remark}

The remaining finite reduction first forgets the signs of opposite faces.  Two
faces are in the same \emph{opposite-face pair} if their supporting planes
are parallel.  There are seven such pairs:
\[
x,\ y,\ z,\ d_{111},\ d_{11\bar 1},\ d_{1\bar 1 1},\
d_{\bar 1 11}.
\]
The first three are square-face pairs.  The last four are triangular-face
pairs, named by the projective normal direction of the pair.

\begin{definition}[Started pair word]
A \emph{started pair word} is the length-\(13\) word in the seven
opposite-face pairs obtained from a started itinerary after deleting the
initial face \(X_+\) and then replacing every remaining face by its
opposite-face pair.  It is \emph{valid} if the multiplicities are
\[
x:1,\qquad y:2,\qquad z:2,\qquad
d_{111},d_{11\bar 1},d_{1\bar 1 1},d_{\bar 1 11}:2.
\]
The finite set of valid started pair words is denoted by \(\W\).
\end{definition}

The number of valid started pair words is
\[
  |\W|=\frac{13!}{2^6}=97{,}297{,}200.
\]
Lean defines two functions, called \(\rank\) and \(\unrank\), that give a
lexicographic address for this finite set:
\[
  \unrank:\{0,\ldots,97{,}297{,}199\}\to\W.
\]
The word ``rank'' here means only an address in a finite list.  It is not a
matrix rank or a geometric invariant.  Lean proves that the address map and
its inverse enumerate exactly the valid started pair words
(\leanref{validPairWord\_card\_literal}, \leanref{unrankPairWord\_valid}).

In the branch where the linear return map is the identity, the affine
translation vector depends on which member of each opposite-face pair was
used.  Once the first face \(X_+\) is fixed, the remaining choices are encoded
by six independent bits.  We call these six bits a \emph{sign mask} and write
\[
  \Masks=\{\pm1\}^6.
\]

\section{The Linear Return Map and Its Normal Form}
\label{sec:holonomy}

The linear part \(M_s\) of the unfolded return map depends only on the started
pair word, not on the sign mask.  We write \(M(w)\) for this linear part.  The
Lean product convention is
\[
  R(w_0)R(w_1)\cdots R(w_{12})R(x),
\]
where \(R(\cdot)\) is the linear reflection associated to an opposite-face
pair, and the final factor \(R(x)\) comes from the initial face \(X_+\).

The word \emph{holonomy} is used here in a modest sense.  It means the linear
effect of transporting a direction through the full sequence of face
reflections.  A \emph{normal form} for this holonomy is a smaller exact
summary from which Lean can decide whether \(M(w)=I\).

\begin{definition}[Square parity]
The square-pair reflections \(x,y,z\) are diagonal sign changes.  Their
accumulated effect is recorded by
\[
  p=(p_x,p_y,p_z)\in(\Z/2\Z)^3.
\]
Scanning a square-pair letter toggles the corresponding coordinate of \(p\).
Scanning a triangular-pair letter leaves \(p\) unchanged.
\end{definition}

\begin{definition}[Triangular shadow]
Let
\[
  \T=\{111,\ 11\bar 1,\ 1\bar 1 1,\ \bar 1 11\}
\]
be the four triangular projective normal directions.  When a triangular
letter is scanned after the current square parity \(p\), the square sign
changes act on it.  If the triangular letter is written projectively as
\((1,\eta,\zeta)\), then \(p\) sends it to
\[
  \bigl(1,\ (-1)^{p_x+p_y}\eta,\ (-1)^{p_x+p_z}\zeta\bigr).
\]
The \emph{triangular shadow} is the stack of acted triangular letters
obtained while scanning the pair word, with adjacent equal letters cancelled.
The final reduced stack is denoted \(\red(w)\).
\end{definition}

\begin{theorem}[Lean-checked holonomy classifier]
For every valid started pair word \(w\),
\[
  M(w)=I
  \quad\Longleftrightarrow\quad
  \red(w)=[].
\]
In the Lean development this theorem is named
\begin{center}
{\small\ttfamily totalLinearOfPairWord\_eq\_identity\_iff\_}\\
{\small\ttfamily reducedShadow\_empty\_of\_valid}
\end{center}
\end{theorem}

\begin{proof}[Proof idea]
The scan maintains a product invariant: the accumulated pair-reflection
product factors as a triangular product times the current square-parity
matrix.  Valid pair-word counts imply that the final square parity is
trivial once the started \(x\) factor is included.

Adjacent equal triangular reflections square to the identity, so cancelling
adjacent equal letters does not change the triangular product.  It remains to
show that a nonempty reduced triangular word cannot have identity product.

For a triangular normal \(n\in\{\pm1\}^3\), the reflection matrix is
\[
  H_n=I-\frac{2}{3}nn^T.
\]
Scale it to the integer matrix
\[
  K_n=3H_n=3I-2nn^T.
\]
Because \(-2\equiv1\pmod 3\), one has \(K_n\equiv nn^T\) modulo \(3\).  A
nonempty reduced triangular word therefore gives, modulo \(3\), a product of
rank-one matrices.  Since adjacent projective triangular letters are
distinct, every successive dot product is nonzero in \(\mathbb F_3\).  The
product is a nonzero scalar multiple of an outer product, hence is nonzero
modulo \(3\).  If the rational triangular product were \(I\), the scaled
integer product of length \(m>0\) would be \(3^mI\), which is zero modulo
\(3\), a contradiction.
\end{proof}

\begin{remark}
An exact external scan found \(2{,}468{,}088\) empty reduced shadows and
\(94{,}829{,}112\) nonempty reduced shadows.  These counts are useful
diagnostics, but the proof does not rely on them.  The Lean theorem above is
the trusted identity/nonidentity split.
\end{remark}

\section{The Nonidentity Branch}
\label{sec:nonidentity}

The \emph{nonidentity branch} consists of valid started pair words with
\(\red(w)\ne[]\).  By the holonomy classifier, these are exactly the words
whose linear return map satisfies \(M(w)\ne I\).

Suppose a signed itinerary realizing such a word had an unfolded witness.
The return map \(A(p)=Mp+b\) would carry the witness line to itself.  The line
direction \(v\) would satisfy \(Mv=v\), and the base point \(p_0\) would lie
on an affine line constrained by the following equation.

\begin{lemma}[Forced-axis equation]
Let \(A(p)=Mp+b\) with \(M\ne I\).  If \(A\) preserves the line
\(p_0+\R v\) and preserves its direction, then \(v\ne0\), \(Mv=v\), and there
is \(\lambda\in\R\) such that
\[
  (I-M)p_0=b-\lambda v.
\]
\end{lemma}

\begin{proof}
The direction condition gives \(Mv=v\).  Since \(A(p_0)\) lies on the same
line, \(Mp_0+b=p_0+\lambda v\) for some \(\lambda\).  Rearranging gives the
displayed equation.
\end{proof}

The phrase \emph{forced axis} refers to the affine line, or affine family of
lines, described by this equation together with the eigenvector condition
\(Mv=v\).  Many nonidentity cases are ruled out immediately.  There may be no
compatible nonzero fixed direction, the forced crossing direction may have
the wrong sign, the forced signed face sequence may fail to be omnihedral,
the forced axis may miss the relative interior of \(X_+\), or a required
impact may fall outside the intended face.  Each of these failure modes has a
certificate format whose soundness is proved in Lean
(\leanref{checkNonIdCert\_sound}).

The remaining nonidentity cases are grouped into \emph{semantic families}.  A
semantic family is a mathematical predicate saying that a face sequence has
certain structural features; it is not a list of numerical ranks.  The
dominant residual family is called the \emph{top-pairing} family.  The name is
only a label for one residual pattern in the triangular cancellation data.
Its semantic predicate records:
\begin{enumerate}[leftmargin=2em]
\item a fixed cancellation-pairing pattern in the triangular shadow;
\item an allowed-face schedule at each of the fourteen contribution steps;
\item a square-gap condition, meaning a restriction on where square faces may
  occur relative to triangular contributions;
\item local-axis sign tests, meaning exact rational positivity tests computed
  from prefix reflection matrices;
\item compatibility with a canonical bad face whose interior margin is being
  tested.
\end{enumerate}

A semantic family is called \emph{closed} when the information needed to
check membership can be advanced one face at a time without leaving the
finite state space assigned to the family.  This closure condition lets the
finite-state potential route of Section~\ref{sec:bellman} avoid storing one
proof per rank.

\section{Finite-State Potential Certificates}
\label{sec:bellman}

This section gives the elementary finite-state potential argument used in
the nonidentity branch.  The potential inequality is of the kind that appears
in Bellman's work on routing and dynamic programming~\cite{bellman}, so we
call a certificate of this form a \emph{Bellman certificate}.  No analytic
approximation is involved.

\begin{definition}[Bellman graph]
A Bellman graph consists of states \(S\), directed transitions
\[
  e=(s,g,t),\qquad s,t\in S,\quad g\in\Z,
\]
and a potential function
\[
  V:S\to\Z.
\]
The transition \(e=(s,g,t)\) is \(V\)-valid if
\[
  g+V(t)\le V(s).
\]
The integer \(g\) is called the gain of the transition.
\end{definition}

\begin{lemma}[Telescoping potential inequality]
If
\[
  s_0\xrightarrow{g_0}s_1\xrightarrow{g_1}\cdots
  \xrightarrow{g_{m-1}}s_m
\]
is a path whose transitions are all \(V\)-valid, then
\[
  \sum_{i=0}^{m-1}g_i+V(s_m)\le V(s_0).
\]
In particular, if \(V(s_m)\ge0\), then
\[
  \sum_{i=0}^{m-1}g_i\le V(s_0).
\]
\end{lemma}

\begin{proof}
Sum the local inequalities \(g_i+V(s_{i+1})\le V(s_i)\).  The intermediate
potential terms cancel.
\end{proof}

In the geometric application, a forced-axis semantic family supplies an exact
rational margin \(\mu\).  The margin is chosen so that every feasible
unfolded witness in the family would force
\[
  \mu>0.
\]
After clearing denominators, Lean works with an integer-scaled margin.  A
Bellman certificate proves the opposite inequality: every accepted object in
the semantic family has scaled margin at most \(0\).

\begin{proposition}[Family-level Bellman certificate]
Let \(X\) be a set of finite objects, each with a word of labels
\(\word(x)\).  Suppose there are:
\begin{enumerate}[leftmargin=2em]
\item a deterministic transition function that reads the labels of
  \(\word(x)\), accumulates integer gains, and either succeeds or fails;
\item a potential \(V:S\to\Z\);
\item a constant \(c\in\Z\);
\item an integer-scaled margin \(\mu:X\to\Z\).
\end{enumerate}
Here an \emph{accepted} object means an object satisfying the family
predicate being certified.  Assume that every accepted object \(x\) has a
successful run ending at \(s_f\) with total gain \(G\), that \(V(s_f)\ge0\),
that
\[
  \mu(x)\le c+G,
\]
that every local transition satisfies \(g+V(t)\le V(s)\), and that the root
bound \(c+V(s_0)\le0\) holds.  Then every accepted object has
\[
  \mu(x)\le0.
\]
\end{proposition}

\begin{proof}
The telescoping lemma gives \(G\le V(s_0)\).  Hence
\[
  \mu(x)\le c+G\le c+V(s_0)\le0.
\]
\end{proof}

The generic form of this argument is checked in Lean; for example,
\leanref{const\_add\_bellmanGainSum\_nonpos\_of\_path} is the path version of
the proposition.

\subsection{A Transducer Interface for the Residual Family}

A deterministic finite-state evaluator that reads one input symbol at a time
and updates its state is often called a \emph{transducer}.  In this project,
the input symbols are faces, and the output accumulated along the run is the
integer Bellman gain.

The checked nonidentity interface uses a transducer state for the
top-pairing family.  This state stores:
\begin{enumerate}[leftmargin=2em]
\item the current step number;
\item the current square-gap count;
\item a cursor into the target triangular shadow, meaning the fixed
  triangular-shadow pattern defining this family;
\item the current square parity;
\item the current exact linear reflection product.
\end{enumerate}
The predicate
\begin{center}
  \texttt{TopPairingTransducerTail}
\end{center}
means that this state is semantically consistent with the remaining suffix of
faces.  It packages the schedule, square-gap, and local-axis suffix facts
together with the target-shadow cursor.

The Lean file \texttt{TopPairingTransducerEvalBridge.lean} proves two facts
for use by generated proof files.
\begin{enumerate}[leftmargin=2em]
\item If every semantically valid head step has a graph transition, then the
  combined face evaluator succeeds on the whole semantic tail.
\item In the invariant-carrying version, generated code may maintain an
  additional finite invariant.  Lean proves that local, invariant-preserving
  transition totality suffices for a successful Bellman evaluation at the
  given rank.
\end{enumerate}
The key theorem names are
\begin{center}
{\small\ttfamily evalLabelStepFn\_exists\_of\_tail\_and\_invariantLocal}\\
{\small\ttfamily evalLanguageAtRank\_of\_invariantLocal}
\end{center}
With this interface, a generated module does not replay hand-picked prefixes
or traces at particular rank addresses.  It proves local transition coverage
for semantic states, and Lean performs the recursive evaluation and the
projection to the ordinary Bellman graph evaluator.

The repository also contains generated smoke tests for this interface.  A
\emph{smoke test} here is a small Lean module proving that the interface
works on a bounded example.  These tests check the shape of the generated
proof, but they are not exhaustive coverage.

\section{The Identity Branch}
\label{sec:translation}

The \emph{identity branch} consists of valid started pair words with
\(\red(w)=[]\).  By the holonomy classifier, these are exactly the words whose
linear return map is the identity.  For a signed itinerary in this branch,
the affine return map has the form
\[
  A(p)=p+b.
\]
It is therefore a translation by the vector \(b\).

For a nondegenerate periodic unfolded witness, the line direction must be
parallel to \(b\).  Since the first face is \(X_+\), write the starting point
as
\[
  p_0=(1,y,z).
\]
For a fixed pair word and sign mask, the face-interior and crossing-order
conditions become strict rational linear inequalities in the two variables
\(y\) and \(z\).

If the \(i\)-th developed face plane is
\[
  u_i\dotp p=d_i,
\]
then the crossing time along direction \(b\) is
\[
  t_i=\frac{d_i-u_i\dotp p_0}{u_i\dotp b}.
\]
The denominator \(D_i=u_i\dotp b\) must have the correct sign for a forward
crossing.

\begin{definition}[Good direction condition]
An identity-branch signed case satisfies the \emph{good direction condition}
if all internal crossing denominators \(D_i\) have the required positive sign
after the fixed orientation convention is chosen.  In the Lean code this
predicate is named \texttt{GoodDirection}.
\end{definition}

\begin{lemma}[Good direction is necessary]
If an identity-branch signed itinerary has an unfolded witness, then it
satisfies the good direction condition.
\end{lemma}

\begin{proof}
Each prescribed developed face must be crossed in forward time and from the
prescribed side.  With the fixed orientation, the numerator in the displayed
formula for \(t_i\) has the prescribed sign.  A nonpositive denominator would
reverse or degenerate that crossing.
\end{proof}

In Lean this lemma is \leanref{goodDirection\_of\_translation\_feasible\_at\_rank}.
Once the good direction condition is imposed, the remaining constraints have
the form
\[
  a_jy+c_jz+e_j>0
\]
with rational coefficients.  Lean checks infeasibility using the following
strict two-variable form of Farkas' lemma.

\begin{lemma}[Strict two-variable Farkas certificate]
Suppose nonnegative rational multipliers \(q_j\), not all zero, satisfy
\[
  \sum_j q_ja_j=0,\qquad
  \sum_j q_jc_j=0,\qquad
  \sum_j q_je_j\le0.
\]
Then there are no \(y,z\in\R\) satisfying all inequalities
\[
  a_jy+c_jz+e_j>0.
\]
\end{lemma}

\begin{proof}
If all strict inequalities held, multiplying them by the nonnegative \(q_j\)
and summing would give a strictly positive number.  The coefficient sums make
the \(y\) and \(z\) terms vanish, while the constant sum is nonpositive, a
contradiction.
\end{proof}

A generated Farkas certificate names the inequalities it uses.  The proof
does not trust a row merely because a script printed it.  Each row is
reproduced in Lean from a geometric source, such as a start-face condition,
an ordering condition, or an impact-face interior condition, and Lean checks
the rational linear combination (\leanref{FarkasCert.Valid.sound}).

\section{Generated Coverage}
\label{sec:coverage}

The word \emph{certificate} in this project means finite data together with a
Lean theorem or checker proving that the data imply a mathematical
obstruction.  The word \emph{coverage} means that every case in the finite
search space is assigned to some checked obstruction.

The public generated predicates are deliberately small.  The nonidentity
predicate is
\begin{center}
  \texttt{NonIdentityRankKilled r}.
\end{center}
It means that if rank \(r\) is in the nonidentity branch, then no started
signed itinerary realizing that rank has an unfolded witness.  The
identity-branch predicate is
\begin{center}
  \texttt{TranslationCaseKilled r mask}.
\end{center}
It means that if rank \(r\) is in the identity branch, then the signed
translation case indexed by the sign mask has no unfolded witness.

\begin{definition}[Semantic generated coverage]
Semantic generated coverage consists of:
\begin{enumerate}[leftmargin=2em]
\item the Lean-checked rank and unrank address space for all
  \(97{,}297{,}200\) valid started pair words;
\item the Lean-checked \(64\)-element sign-mask address space;
\item a proof of \texttt{NonIdentityRankKilled r} for every rank \(r\);
\item a proof of \texttt{TranslationCaseKilled r mask} for every rank
  \(r\) and every sign mask.
\end{enumerate}
\end{definition}

\begin{proposition}[Coverage kills started unfolded witnesses]
If semantic generated coverage holds, then no started omnihedral itinerary
has an unfolded witness.
\end{proposition}

\begin{proof}
Let a started unfolded witness be given.  Forgetting signs gives a valid
started pair word \(w\), hence a rank \(r=\rank(w)\).  By the holonomy
classifier, either \(\red(w)\ne[]\) and the case is nonidentity-linear, or
\(\red(w)=[]\) and the case is identity-linear.

In the nonidentity case, \texttt{NonIdentityRankKilled r} contradicts the
witness.  In the identity case, the signed itinerary determines a sign mask
\(m\), and \texttt{TranslationCaseKilled r m} contradicts the witness.
\end{proof}

\begin{theorem}[Current formal theorem]
If \texttt{ExhaustiveGeneratedCoverage} is supplied, then the
cuboctahedron has no nonsingular omnihedral periodic billiard orbit.
\end{theorem}

\begin{proof}
Assume such an orbit exists.  Cyclically reindex it to start at \(X_+\).  The
unfolding criterion gives a started unfolded witness.  The previous
proposition, instantiated by the supplied coverage object, rules this out.
\end{proof}

\section{Verification Boundary}
\label{sec:validation}

The trusted part of the project is the Lean development, including:
\begin{enumerate}[leftmargin=2em]
\item exact rational definitions of the cuboctahedron, faces, and reflection
  maps;
\item the unfolding criterion and started-itinerary reduction;
\item the rank and unrank enumeration theorem for valid pair words;
\item the holonomy normal form and identity classifier;
\item the good direction necessity theorem for identity-branch cases;
\item the strict rational Farkas soundness theorem and row-source checkers;
\item the generic Bellman potential theorems;
\item the top-pairing semantic language, transducer-tail predicate, and
  deterministic evaluator bridge;
\item generated Lean modules, to the extent that they prove the
  theorem-valued predicates consumed by the coverage interface.
\end{enumerate}

The untrusted part consists of profilers, search scripts, JSON files,
Markdown reports, old C++ outputs, and bounded smoke tests.  These artifacts
may suggest certificate data or test the shape of a generator.  They become
proof only when Lean checks a theorem that consumes them.

For the current conditional proof surface, the repository checks are:
\begin{verbatim}
lake exe cache get
lake build Cuboctahedron.ConditionalTheorem
lake env lean Cuboctahedron/PrintConditionalAxioms.lean
grep -R "sorry\|admit\|axiom\|native_decide\|unsafe" Cuboctahedron
\end{verbatim}
The axiom check reports only \texttt{propext}, \texttt{Classical.choice},
and \texttt{Quot.sound}.  The text search matches only the
\verb|#print axioms| commands themselves and an ordinary English use of the
word ``admit'' in a comment.  When the unconditional theorem is in place, a
corresponding file \texttt{Cuboctahedron/PrintAxioms.lean} will print its
axioms.
