# Documentation

This directory holds the project's technical reports and development history. For
an overview of the problem, the proof strategy, and the current status, start with
the [top-level README](../README.md). For a self-contained mathematical account, see
the [paper](../paper/cuboctahedron_no_omnihedral.tex).

> [!NOTE]
> Nothing in this directory is part of the formal proof. The reports record exact
> diagnostics produced by external scripts. They guide the engineering, but a claim
> counts only once a Lean theorem checks it. Several reports are regenerated by
> scripts under [`scripts/`](../scripts), so their file names are stable.

### Operational logs

The `bellman_split_*` files are crash-recovery and batch-planning records for
memory-guarded Lean smoke runs. They are kept for reproducibility and contain no
mathematical content.
